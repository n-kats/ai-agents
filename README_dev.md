# 基本要素
* エージェント
* チャンネル
* 管理機構（オーケストレーション）
* コマンド

# エージェント
タスクを実行するための主体

# チャンネル
エージェント同士がコミュニケーションを行うための媒体

# 管理機構（オーケストレーション）
* エージェント・チャンネルの作成・制御・起動等
* エージェント・チャンネル間の通信
* エージェント・チャンネルの状態管理

# 初期コンセプト
* エージェントは基本エージェントと管理エージェントからなる。
* 基本エージェントは、通常のタスクエージェントとチャンネルエージェントに分かれる。
* エージェントはLLMを使った実装が主だが、必ずしもそうとは限らない（動画を逐次的に読むものとかも想定）
* 管理エージェントは基本エージェントに対応して、タスクエージェント管理エージェント・チャンネルエージェント管理エージェントがある。
* 基本エージェントの記憶は独立している。
* タスクエージェントとチャンネルエージェントはM:Nで接続されている。（処理の過程で接続関係は変化する）
* チャンネルエージェントは、タスクエージェントに対して以下のことができる
  * 平時：ブロードキャスト・メッセージ送信（特定エージェントに）・チャンネル推薦（「その話題はあっちのチャンネルの方がよい」）
  * 終了中：チャンネル推薦
  * 終了：エラー送信
* タスクエージェントは、チャンネルエージェントに対して以下のことができる
  * 接続・離脱
  * メッセージ送信
  * 履歴取得・要約版履歴取得（フローorストック情報として取得）
  * チャンネル情報（他のエージェント情報など）取得（「〇〇エージェントに〇〇を聞きたい」みたいなメッセージ作成に行う）
* 管理エージェントは、エージェントからの要求等に応じて以下のことができる
  * エージェント作成
  * エージェント検索
  * エージェント制御（停止等）
* 人間の介入方法は、個別のエージェントで適切なものを選ぶ
  * ファイル
  * WebUI（動画読み込みエージェントとかはこれ？）
  * CUI
  * （実装面）エージェント毎にデータ形式を定義しないといけない場合は、実行時コード生成をする（人間が確認しながら使う）。

# 初期エージェントからの変更
チャンネルエージェントは、単にチャンネルとしての機能（情報の集約所）に制限して、チャンネルエージェントはタスクエージェントに実施させる。それにともない、タスクエージェントは単にエージェントと呼ぶことにする。

# research_agent_v1のファイル実装内容

- **graph.py**: langgraphを利用して、エージェントの全体構造および依存関係となるグラフの定義を実装します。
- **nodes.py**: エージェントが利用する各機能をモジュール化したノード定義を配置します。
- **utils.py**: 共通的なユーティリティ関数（例：データ処理、補助処理など）を提供します。
- **promptsディレクトリ**: プロンプト生成用のテンプレートファイルを配置するディレクトリです。各種プロンプト（例：初期化、エラーハンドリング、ユーザーガイドなど）のJinja2テンプレートを格納します。

## モジュール構成
1. **調査エージェント（DataGathering Agent）**
   - Webやローカルデータソースから情報を抽出。
   - キーワードや論文、技術文書を検索し、結果を集約。

2. **分析・統合エージェント（Analysis & Synthesis Agent）**
   - 情報を要約、分類し、深い分析を実施。
   - ローカルLLM APIを利用して自然言語生成と質問応答を行う。

3. **ワークフロー管理モジュール（Workflow Manager）**
   - 調査タスクを管理し、エージェント間でのタスク渡しや状態保持を行う。
   - 処理の途中経過や結果を整理し、出力。

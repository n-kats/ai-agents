# Plans ディレクトリ

`docs/plans/` には、具体的な実装に関わる計画・永続化案・運用手順などを保管します。  
設計方針や概念整理は `docs/concept.md`、仕様策定は `docs/specs/`、ワークフロー化された ExecPlan は `docs/workflows/` に配置する点に注意してください。

- フィーチャー固有のデータベース設計や永続化プラン
- 実装ステップを伴う検証メモ
- 長期的に参照する構成図や設定例

記述時は対象機能・前提・検証手順を明確にし、関連する仕様 (`docs/specs/`) や進捗管理 (`docs/implementation_status.md`) へリンクを追加してください。

# コーディングガイドライン

## インポート

- 相対インポートは禁止し、常に絶対インポートを使用すること。

  ```python
  # Bad
  from . import utils
  from .. import models

  # Good
  # (プロジェクトルートからの絶対パスで記述)
  # from project_name.module import submodule
  # from project_name import models

## テストファイルの配置

- テストコード (`test_*.py`) は、原則としてテスト対象の Python ファイルと同じディレクトリに配置すること。
  - 例: `module/submodule/logic.py` のテストは `module/submodule/test_logic.py` とする。
- これにより、関連するコードとテストが近くに配置され、発見と保守が容易になる。

## `if __name__ == "__main__":` の使用

- `if __name__ == "__main__":` ブロックは、主に以下の目的で使用すること。
  - スクリプトとして直接実行される際の処理（例: コマンドラインインターフェースのエントリーポイント）。
  - テストファイル (`test_*.py`) 内でのテスト実行や、デバッグ目的での簡易的な実行コード。
- ライブラリとして他のモジュールからインポートされることを主目的とするファイル（例: クラス定義、関数定義、設定定義などを含むモジュール）では、原則としてこのブロックを使用しないこと。モジュールインポート時に意図しない副作用が発生することを防ぐため。

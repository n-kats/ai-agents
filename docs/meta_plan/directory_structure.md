# ディレクトリ構造

本書は、プロジェクト全体のディレクトリ構造および各コンポーネントの役割を明示するものである。

## エージェントディレクトリ構造
各エージェントは固有のディレクトリを有し、その中に関連ファイルを配置する。

### エージェント名/
- main.py
  - エージェントのメイン実行ファイル。
  - グラフの構築、コンパイル（必要に応じて）、および実行を担当する。
  - `if __name__ == "__main__":` ブロックを含む。
- graph.py
  - エージェントの全体構造および依存関係を表すグラフ定義（StateGraph）を実装する。
  - 主たる目的は、StateGraphを返す `build_xx_graph` 関数の作成である。
  - モデルやエージェントのインスタンスを引数として受け取ることがある。
  - `graph.compile()` はこのファイル内では呼び出さない。
- nodes.py
  - エージェントが利用する各機能（ノードとしてグラフに追加される関数やクラスメソッド）の定義を格納する。
- utils.py
  - 共通のユーティリティ関数（例：データ処理、補助処理等）を提供する。
- prompts/  
  - プロンプト生成用のテンプレートファイルを格納するディレクトリである。
  - *.j2 ファイル  
    - 各種プロンプト（例：初期化、エラーハンドリング、ユーザーガイド等）のJinja2テンプレートを含む。

# Directory Structure Documentation Template

本ドキュメントは任意のプロジェクトでディレクトリ構造を整理する際のテンプレートです。各リポジトリに合わせて項目を編集し、プロジェクト固有の内容は別ファイル（例: [docs/directory_structure.md](../directory_structure.md)）に記載してください。

## 推奨セクション例
- **ルート構成**: 主要ディレクトリと設定ファイルの役割を一覧化する。
- **ソースコード領域**: フレームワーク層、アプリケーション層、プリセットなどを分けて説明する。
- **ドキュメント領域**: 現行仕様、ガイドライン、レガシー資料などの分類ルールを記載する。
- **生成物 / キャッシュ**: 実行時に作成されるディレクトリの配置とクリーニング方針。
- **更新指針**: ディレクトリが追加・変更された際にドキュメントをどう更新するかを明記する。

## 記述方針
1. **プロジェクト固有情報は分離**: テンプレートは汎用的な構成とし、具体的なパス・サービス名は別ドキュメントに抜き出す。
2. **粒度の統一**: セクションごとに同じ粒度で説明し、冗長な詳細は参照リンクにまとめる。
3. **メンテナンスしやすさ**: ディレクトリ追加・削除時にどのファイルを更新するかを明示しておく。

## 利用方法
- 新規プロジェクトで構造ガイドを作成する際は本テンプレートをコピーし、各セクションに具体例を記入する。
- 既存プロジェクトでは、テンプレートを `docs/meta_plan/` に保持しつつ、実態を `docs/` 側にまとめる運用とする。
- 他プロジェクトへ転用する場合は、テンプレートに共通部分を残し、固有情報は別のガイドファイルへ追加する。

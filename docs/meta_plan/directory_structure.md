# ディレクトリ構造

このドキュメントはプロジェクト全体のディレクトリ構造と、各コンポーネントの役割について記述しています。

## エージェントディレクトリ構造
各エージェントは独自のディレクトリを持ち、その中に関連するファイルを配置します。

### エージェント名/
- graph.py  
  - エージェントの全体構造および依存関係となるグラフの定義を実装します。
- nodes.py  
  - エージェントが利用する各機能をモジュール化したノード定義を配置します。
- utils.py  
  - 共通的なユーティリティ関数（例：データ処理、補助処理など）を提供します。
- prompts/  
  - プロンプト生成用のテンプレートファイルを配置するディレクトリです。  
  - *.j2 ファイル  
    - 各種プロンプト（例：初期化、エラーハンドリング、ユーザーガイドなど）のJinja2テンプレートを格納します。

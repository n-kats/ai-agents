# Makefile ポリシー

このドキュメントは、Makefileを用いてコードの静的解析、整形、テストなどの自動化を実現するための一般的な方針を記述しています。  
以下のポリシーは、どのプロジェクトでも共通して利用可能な形となっています。

- **TARGET変数**  
  TARGET変数は、対象ディレクトリを指定するために利用されます。  
  デフォルト値は任意に定めることができ、各プロジェクトの要件に応じて変更してください。

- **lintターゲット**  
  指定されたTARGETに対して、[ruff](https://www.ruff.rs/)による静的解析と、[mypy](http://mypy-lang.org/)による型チェックを実行し、コード品質の維持を図ります。

- **formatターゲット**  
  指定されたTARGETディレクトリに対して、[ruff format](https://www.ruff.rs/)コマンドを用いてコードを整形し、[ruff check --fix](https://www.ruff.rs/)で自動修正を試みます。

- **testターゲット**  
  `pytest` を用いてテストを実行し、コードの動作確認を行います。

以上のポリシーに基づいてMakefileを構築することで、さまざまなプロジェクトに柔軟かつ再利用可能な設定を提供できます。

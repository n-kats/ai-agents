# Meta Guidelines Templates

`docs/meta_plan/` にはプロジェクトを問わず再利用できる
テンプレートや方針サンプルを置きます。個別リポジトリでは、
ここにあるドキュメントをベースに必要な部分をコピーし、
プロジェクト固有の内容は `docs/` 直下など別の場所へ
記載してください。

- プロジェクト横断で共通化できるポリシー（コーディング規約、コメント方針など）
- ドキュメント整理やディレクトリ構造を記述する際のテンプレート
- 他プロジェクトに転用する時に参考となる汎用ルール
- Mermaid 図作成時の反省や共通的な落とし穴 (`mermaid_diagram_reflection.md`)
- 長時間タスク向けの実行計画テンプレート (`exec_plan_guidelines.md`)

ここにプロジェクト固有情報を直接追加したい場合は、
別ファイルへ切り出してからリンクする運用を推奨します。

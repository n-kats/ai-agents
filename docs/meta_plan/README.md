# Meta Guidelines Templates

`docs/meta_plan/` にはプロジェクトを問わず再利用できる
テンプレートや長期的な計画メモを置きます。個別リポジトリでは、
ここにあるドキュメントをベースに必要な部分をコピーし、
プロジェクト固有の内容は `docs/` 直下など別の場所へ
記載してください。

- ディレクトリ構成や進行計画を記述するテンプレート
- 他プロジェクトに転用する時に参考となる汎用ルールの下書き
- 中長期の開発ロードマップやメタ的な計画ノート
- 詳細なガイドライン本文は `docs/guides/` に配置し、ここでは再利用テンプレートのみを維持する
- ワークフロー本体のガイドラインは `docs/workflows/` で管理する

ここにプロジェクト固有情報を直接追加したい場合は、
別ファイルへ切り出してからリンクする運用を推奨します。

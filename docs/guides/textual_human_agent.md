# Textual Human Agent UI 概要

`TextualHumanAgent` が表示する画面構成と操作手順をまとめます。スレッド環境向けにシグナル登録を抑制した場合も同じレイアウトで表示されますが、一部の端末イベント（ウィンドウリサイズ通知やサスペンド処理）が無効になる点に注意してください。

## 画面構成
- **ヘッダー**: Textual 標準の `Header` を使用し、右上に時計を表示します。
- **チャネル選択パネル（左側）**
  - タイトル: `送信先チャネル`
  - `Select` ウィジェット: 参加済みチャネルを表示し、`__all__` を選ぶと全チャネルへ送信します。
  - `Button` (`チャネルを更新`): チャネル一覧を最新化します。
  - `Button` (`終了`): アプリケーションを終了します。
- **ログパネル（右側上段）**
  - `RichLog`（利用できない環境では `TextLog` / `Log`）で受信・送信履歴を表示し、長文はウィジェット幅に合わせて自動折り返しされます。
  - 受信メッセージは `[IN ][チャネル名]`、送信メッセージは `[OUT][チャネル名]` のヘッダー付きで記録します。
- **ステータス表示（右側中段）**: 直近の操作結果や警告をテキストで表示します。
- **入力欄（右側下段）**: `Input` ウィジェットでメッセージ本文を入力し、`Enter` で送信します。
- **フッター**: Textual 標準の `Footer`。主要なキーバインドを表示します。

## 操作フロー
1. 起動直後にチャネル一覧を取得し、`Select` に反映します。`Ctrl+R` または `チャネルを更新` ボタンで再取得できます。
2. ログは 0.3 秒ごとに未読メッセージをポーリングし、受信内容を即座に表示します。フォーカスはメッセージ入力欄へ自動で戻ります。
3. 送信時は直近の受信メッセージから `request_id` を継承し、存在しない場合は `human-0001` 形式で自動採番します。
4. コマンド入力:
   - `/help` : 利用可能なコマンド一覧（`/help`, `/quit`）をステータスに表示します。
- `/quit` : アプリを終了します。従来どおり `Ctrl+C` でも終了できます。
  - ウィンドウを直接閉じた場合でも内部で停止処理が走り、マネージャー全体が順次終了します。

## 既知の制約
- スレッド実行環境では端末シグナルを登録できないため、ウィンドウリサイズの即時反映やサスペンド関連機能が動作しません。必要に応じてメインスレッドで実行してください。
- Textual のバージョン差異により、チャネルログには `TextLog` / `Log` / `RichLog` のいずれかが選択されます。`RichLog` が利用できる環境では折り返し表示が有効になりますが、旧バージョンでは横スクロールが必要な場合があります。
